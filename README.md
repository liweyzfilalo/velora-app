# Velora pour Windows

Téléchargements de l'application de bureau [Velora](https://velora-musique.netlify.app).

**[⬇ Télécharger Velora pour Windows](https://github.com/liweyzfilalo/velora-app/releases/latest/download/Velora-Setup.exe)**

Installation en un clic, raccourcis sur le bureau et dans le menu Démarrer.
Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur
**Informations complémentaires**, puis **Exécuter quand même** (l'installateur n'est pas signé).

L'application affiche le site Velora : elle se met à jour automatiquement, sans réinstallation.
