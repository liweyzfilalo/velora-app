## Télécharger

| Plateforme | Lien |
|---|---|
| 🪟 **Windows** | [Velora-Setup.exe](https://github.com/liweyzfilalo/velora-app/releases/latest/download/Velora-Setup.exe) |
| 🤖 **Android** | [Velora.apk](https://github.com/liweyzfilalo/velora-app/releases/latest/download/Velora.apk) |
| 🍎 **iPhone / iPad** | Ouvrir [le site](https://velora-musique.vercel.app) dans Safari, puis Partager → « Sur l'écran d'accueil » |

**Windows** : installation en un clic, avec des raccourcis sur le Bureau et dans le menu Démarrer.
Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur ». Cliquez alors sur
**Informations complémentaires**, puis sur **Exécuter quand même** (l'installateur n'est pas signé).

**Android** : autorisez l'installation depuis cette source quand le téléphone le demande.

Les applications affichent le site Velora : elles se mettent à jour automatiquement, sans réinstallation.
